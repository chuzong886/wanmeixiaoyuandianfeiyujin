# 天枢能源管理 v1.0 · 待验收版

以用电空间为中心，统一管理风险、计量、费用、通知与处理。家庭、宿舍、门店、办公室、厂房使用同一套配置能力，不拆分行业版本。

首次使用请阅读：[天枢能源管理引擎使用指南](docs/天枢引擎使用指南.md)。

## 启动与数据

解压运行包后双击 `Tianshu.Energy.exe`，需保留整个目录。运行时、协议适配器与网页资源均随包提供。仅监听 `127.0.0.1`。

默认数据目录仍为 `%LOCALAPPDATA%\TianshuEnergy`。旧版 `windows-0.3.0` 与 `windows-0.3.1` 未覆盖；旧版源码压缩包保留。首次升级前请退出旧服务并备份整个数据目录，不能同时让新旧服务写同一数据库。

首次无账户时为演示管理模式。通过“后端设置”建立管理员后，须登录。模拟空间、模拟设备和演示预测均有标识。开发与验收仅使用 `build/` 下合成数据，没有清空原数据库。

## v1.0 当前改造

- 设备中心分为“设施与回路”“智能电表”。只读电表没有供电开关；控制功能由设备能力决定。
- 控制器与负载、上下级计量关系分别记录；汇总去重。统计范围有生效时间，历史口径不追溯重写。
- 在线、开关、执行结果分开；指令下发不代表执行成功，迟到读数不授权远程操作。
- 表单使用 ArtForm 与 Element Plus 右侧抽屉；下拉、开关、复选、日期、分页、消息、对话框均使用模板组件；折线/柱状图直接使用 Art Design Pro 图表组件。旧自绘封装已移除。
- 预测中心顶部提供开始预测，输出七日曲线和建议；建议在每日用量上方。支持独立演示选项。
- 告警具有持续、恢复稳定、滞回、通知间隔；监测状态和人工处理状态分开。支持负责人、处理记录、照片、发生时刻曲线、重复事件合并与升级；告警按日期/级别/状态筛选与分页。
- 系统内事件、Webhook、SMTP 配置，测试发送、发送日志与失败重试。凭据加密保存，编辑回显不返回邮件密码。
- 固定/分时/阶梯电价移入空间设置，保留生效版本；实际超预算不依赖预测训练完成，不因此自动断电。
- 余额与累计电量并存时只计一份用量，优先累计电量；短余额区间连续计量；纯功率有积分路径。欠费余额可为负；余额上升标记疑似充值，不当成负耗电。
- 后端设置提供 Logo、重启后生效的端口、空间授权、账户/网关维护、备份恢复、出厂设置。出厂清空需要删除范围预览、短时确认令牌、管理员密码与明确确认。

## AI 分析配置

预测中心的「AI 分析」与本地七日预测是两个独立功能。管理员在「后端设置 → AI 分析 → 配置 AI 接口」填写接口地址、模型、API Key 和预设提示词，选择最近7/14/30天，保存并启用。支持 Chat Completions 兼容协议；可填完整 `/chat/completions` 地址，或填服务商给出的 Base URL（例如以 `/v1` 结尾）。模型名称与 Token 参数应按服务商文档填写，不预置或推荐某个付费模型。

点击分析后，先确认接收接口、数据来源、预设提示词与完整数据包；确认发送后才由后端调用接口，展示并保存真实返回文本。数据含近期用量、估算费用、设备贡献、读数质量与告警摘要；默认使用匿名设备代号，不发送账户、接口密钥、照片和处理说明。管理员可以明确开启发送空间/设备原名。用电及费用数据仍可能敏感，应只使用可信服务。演示数据有标记，不能当成真实运行结论。

密钥使用 Windows 当前账户加密保存，不回显；留空保留同一接口原密钥，更换地址必须重填。远程接口强制 HTTPS，本机接口允许 HTTP。每次确认令牌仅用一次，超时、限流或失败不自动重试，避免重复计费；可在历史分析查看结果。AI 仅提供文字建议，不具备设备控制权限。未配置时不提供假分析结果。

默认 Logo 为本次提供的原始 PNG，上传的自定义 Logo 仍优先显示。AI 测试使用合成数据、模拟 HTTPS 与本机临时 HTTP 服务，未使用真实服务商密钥进行付费调用。

## 数据与预测边界

余额不等于实时功率。仅余额接口不显示功率、电压等不存在的能力。缺测显示暂无数据，不生成零用电日报或虚构峰时。统计完整度按全部入账计量点的共同覆盖判定。

电量均按有效采样区间积分/分摊，费用是估算，不代替供电结算。电价版本按小时统计生效；小时内部没有结算级精度。阶梯按自然月累计，不含需量/容量费、税费或功率因数调整电费。

空间七日预测为“天枢本地加权基线 v1”，至少三个完整历史日后启用；区间为工程参考范围，不是校准置信区间。余额续航沿用本地保守预测适配器并扣除保留电量。没有宣称已接入 PHP Tianshu 3.0 完整算法。

## 验证及仍未完成

进度见 `docs/V1.0实施清单.md`，浏览器证据见项目根目录 `design-qa.md`。构建通过不等于全部需求验收通过。

当前不宣称以下能力已完成：账单核对、按用途/房间分摊费用、完整归因问答、个人基线学习、真实设备自动化计划预览及完整冲突策略。定时开关目前仍限制为非保护模拟设备；真实回路仅通过已配置网关的人工确认/回执流程操作。

真实 Webhook/SMTP 送达、真实硬件控制、真实校园接口未用个人凭据联调。自动回归仅用合成数据及模拟通知连接。v1.0 新业务页面的英文翻译尚未全部补齐。

备份含敏感配置。API/邮件凭据受 Windows 当前账户加密保护，跨电脑或跨 Windows 账户恢复后可能需要重填凭据；不是跨机器免配置迁移。恢复和出厂操作不能撤销，操作前先下载备份。

## 开发

独立电表 API + 网关模拟程序：运行包内双击 `Tianshu.Simulator.exe`，说明见 [模拟平台使用说明](docs/模拟平台使用说明.md)，验收范围见 [模拟平台验收记录](docs/模拟平台验收记录.md)。模拟程序与能源主系统分开保存数据，仅使用本机专用测试网关，不控制物理硬件。

前端：`frontend/` 内安装依赖后执行 `npm run build`。后端：`python backend/server.py --data-dir build/local-dev --port 8791`。

离线业务回归：`python tests/test_energy.py`、`python tests/test_thirdparty.py`、`python tests/test_v1.py`。本机 HTTP 集成：`python tests/test_energy.py --http`。测试不得指向真实数据目录。
