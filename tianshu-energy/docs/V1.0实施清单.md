# 天枢 v1.0 实施跟踪

基线：用户提供的《天枢 · 需求与问题合订本（去重版）》第三至八章，以及此前确认的十九项缺陷。

## 已确定的业务口径

- 余额与累计电量分别存原始读数，同一区间只生成一份用量，优先累计电量。
- 智能电表页面只做计量；带控制电表的开关由关联控制点进入设施与回路操作。
- 费用和预算配置移到空间设置，不再单设电价预算导航。
- 预置预测必须标明演示；真实预测不得使用预置结果伪装实测。
- 恢复出厂仅实现入口与明确确认机制，开发与验收不得清空用户现有数据库。
