# HTTP网关接口与控制回执

该接口已经实现并用合成数据测试，但尚未和任何真实硬件联调。平台默认仅监听本机。适配器与平台可以在同一台电脑上运行，适配器再负责与电表、插座或控制器通信。

## 登记与设备归属

1. 在“后端设置”建立并登录管理员。
2. 在目标空间登记网关，保存仅显示一次的网关ID与令牌。令牌不写入审计日志。
3. 在“设备中心”添加 `HTTP网关设备`，选择当前空间的网关，并填写单相/三相、额定电压、功率和保护规则。
4. 使用页面保存的设备ID作为 `device_id`。当前界面不单独展示ID时，可由已登录的 `/api/snapshot?space_id=...` 响应获得。

所有网关请求需要：

```http
Authorization: Bearer <仅显示一次的网关令牌>
Content-Type: application/json
```

空间、网关和设备必须对应。演示管理员不能登记网关或控制真实网关设备。

## 上报遥测

`POST /api/gateway/telemetry`

```json
{
  "samples": [
    {
      "device_id": "由平台生成的设备ID",
      "ts": 1792584000.25,
      "sequence": 1,
      "power_w": 1200.5,
      "voltage": 220.1,
      "pf": 0.95,
      "relay_on": true
    }
  ]
}
```

示例时间必须替换为当前Unix秒数（允许小数），不是固定可复用值。`power_w` 是总有功功率，单位W；三相设备的 `voltage` 按设备配置为线电压，电流由总功率、线电压和功率因数估算。输入必须为有限数值。

- 一次1至100条样本，样本序号从1开始，每个设备持续递增；重启网关时应保留序号。
- 时间不早于服务器当前时间120秒，不晚于5秒。重复序号、旧时间不会再次计入电量。
- 首次采样不补算之前电量；相邻有效采样间隔超过10秒也不补算缺口。
- 请求中的样本全部先验证，任何格式或归属错误会拒绝整批，不保存部分无效请求。
- 10秒没有新遥测会标记离线。离线功率在汇总中不继续冒充实时数值。

返回：`{"accepted": 1}`。这仅表示采样保存成功，不表示任何控制指令已执行。

当前不接收结算电表的累计电量字段。电量通过功率积分估算，不能声称已支持任意品牌电表或供电账单核验。

## 领取控制指令

`GET /api/gateway/commands`

返回当前网关拥有的未过期指令：

```json
{
  "commands": [
    {
      "id": "指令ID",
      "device_id": "设备ID",
      "desired": 0,
      "state": "queued",
      "reason": "操作者填写的原因",
      "expires": 1792584030.0
    }
  ]
}
```

`desired=0` 表示断开，`desired=1` 表示接通。领取后数据库中的指令进入 `dispatched`，不代表执行完成。请求失败或结果未知时，不得擅自反复触发继电器。

适配器必须根据设备ID找到明确的物理回路，确认指令未过期、现场状态和硬件保护条件允许，再执行。真实协议适配器尚未在此版本提供。

## 执行回执

`POST /api/gateway/ack`

```json
{
  "command_id": "指令ID",
  "success": true,
  "relay_on": false
}
```

只有已领取、未过期、属于当前网关的指令可以确认。`success=true` 且继电器回读状态与目标一致时标记 `confirmed`；否则 `rejected`。之后应继续上报遥测，不能只回执而长期不上报实际功率。

`queued → dispatched → confirmed / rejected`；未收到回执则 `expired`。进程重启时，已经下发但没有结果的指令记为 `unknown`，不会自动重发。

平台的执行确认依赖适配器如实报告硬件回读，不能独立证明触点、线路或负载实际安全。还没有实现硬件互锁、现场旁路开关和厂家控制器协议。

## 界面发起控制的约束

- 已登录且角色为操作员或管理员；演示会话只能控制模拟设备。
- 设备在线、明确允许控制、不是保护回路；同一设备没有另一条待确认指令。
- 填写原因，准确输入目标设备名称；请求包含一次操作唯一的幂等标识。
- 30秒未确认则过期。相同幂等标识不会重复创建操作，内容不符会拒绝。
- 普通用户的开关请求走 Session、CSRF和同源校验，网关令牌不能用来调用普通用户管理接口。

实时网页推送使用 [Server-Sent Events](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events/Using_server-sent_events)，只推送服务端采集结果，断线不会自行生成新采样。

后续若增加MQTT适配，传输层确认不能代替设备执行回执；可参考 [MQTT 5.0应用响应与关联数据机制](https://docs.oasis-open.org/mqtt/mqtt/v5.0/os/mqtt-v5.0-os.html)。本版本未实现MQTT连接。
