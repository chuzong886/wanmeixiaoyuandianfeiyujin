# v1.0 界面设置

平台已使用 Art Design Pro 核心菜单和主题组件。右上角齿轮打开界面设置。

1. 点击浅色、深色或系统主题卡片。顶部日月按钮可以快速切换日夜主题。
2. 点击预设色圆点切换主色，也可以用自定义颜色选择器设置颜色。
3. 语言选择简体中文或 English，实时切换，无需重新登录。
4. 可选择卡片圆角。
5. 面板提示“偏好已保存到本机”后，刷新或重启都可以恢复；本机程序的端口变化不会丢失偏好。

模板菜单、外观组件与既有接口错误保留中英文；v1.0 新业务页英文尚未全部补齐；用户输入的名称、第三方接口返回的原始业务内容、账户信息和请求参数不会被自动翻译或改写。金额仍为人民币，时间仍采用北京时间。

设备接口仍在“设备中心 → 智能电表 → 新增电表 → 第三方 API”中配置。完美校园是可选加密协议，未增加独立校园入口，也未替换设备接入流程。

浅色和深色图表、原生窗口启动、服务数据目录与 API 查询权限保持原有行为。此轮未访问真实校园账号或发送真实硬件控制指令。

前端基于上游 f3aaf58eec1a0e988f162352c33862327a484f95；MIT许可证和集成记录在源码与运行包中附带。浏览器安全策略保持原设置，多语言资源随程序预编译。
