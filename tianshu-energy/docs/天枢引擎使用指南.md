# 天枢能源管理引擎使用指南

适用版本：天枢能源管理 v1.0（Windows 本地版）  
适用场景：家庭、宿舍、门店、办公室、厂房及其他需要用电预警与管理的空间。

## 1. 天枢是什么

天枢以“用电空间”为管理中心，将设备、电表、实时功率、历史电量、费用、余额、预测、告警、通知和处理记录放在同一套系统中。它的目标是让使用者能够回答三个问题：哪里出现异常、还剩多少电或预算、预计什么时候需要处理。

系统既可使用明确标记的模拟数据进行演示，也可以通过第三方查询接口或 HTTP 网关接收真实数据。是否能够远程通断由设备能力决定：只读电表只负责计量；带继电器的电表、智能插座和断路器在接入经过验证的网关并返回执行回执后，才能显示和使用控制功能。

## 2. 安装与首次启动

1. 解压完整的 `Tianshu-Energy-1.0.0-Windows-x64.zip`，不要只复制 EXE。
2. 双击 `Tianshu.Energy.exe`。
3. 等待“天枢能源 · 本地服务中心”显示服务运行中。
4. 点击“打开能源大屏”。实际网页地址以服务中心显示为准。
5. 程序默认只监听本机 `127.0.0.1`，不会自动开放到局域网或互联网。

默认数据保存在：

```text
%LOCALAPPDATA%\TianshuEnergy
```

首次没有本机账户时，系统进入“演示管理员”模式。建议先完成第3章的演示，再到“后端设置 → 账户与网关”建立正式管理员。管理员密码至少12位；创建后页面会退出演示会话，后续需要登录。

> 升级前先退出旧服务并下载备份。不要让新旧版本同时写入同一个数据目录。

## 3. 五分钟快速体验

1. 在顶部空间选择器中选择“示范用电空间”。
2. 打开“设备中心 → 设施与回路”，查看模拟回路的在线状态、当前功率和统计归属。
3. 打开“设备中心 → 智能电表”，查看电表与普通负载的能力差异。
4. 返回“运行大屏”，观察当前功率、今日用电、费用和实时功率曲线。曲线默认显示最近3分钟，将鼠标移到图内并滚动滚轮可调整时间范围。
5. 打开“预测中心”，选择“演示场景”并点击“开始预测”，查看未来七日曲线和建议。
6. 打开“告警中心”，新建一条功率或离线规则，观察事件处理流程。
7. 如需监控演示，启动独立模拟平台，在“监控画面”中接入 JPEG 快照地址。

所有模拟设备、模拟空间和模拟预测都有明显标记。模拟开关只改变软件数据，不会控制物理线路。

## 4. 先理解四个核心对象

### 4.1 用电空间

空间是最上层管理范围，例如“1号门店”“办公楼三层”或“家庭住宅”。每个空间拥有自己的设备、计价方案、预算、规则、监控画面和成员授权。顶部空间选择器决定当前页面正在查看哪个空间。

### 4.2 设备与控制器

- 只读电表：读取计量数据，没有供电开关。
- 带控制电表：读取计量数据，并可通过继电器执行通断；必须收到回执。
- 智能插座：可计量并控制其负载。
- 断路器：控制整个回路，操作前应核对受影响设备。
- 普通用电器：本身没有通信能力时，只能依附控制器，不能假装可以单独控制。

“通信在线”“开关合分”和“指令执行结果”是三种不同状态。离线不等于断电，指令下发也不等于设备已经执行。

### 4.3 计量拓扑

系统支持总表、分表、回路和设备的上下级关系。设置正确的上级电表后，汇总会自动去重。修改统计范围时可以指定生效时间，历史报表不会被追溯改写。

### 4.4 数据可信度

关键读数应同时关注来源、更新时间和“实测／估算／过期”状态。没有数据时系统显示“暂无数据”，不会用0冒充。只有余额的接口不能推导实时功率；陈旧读数不能作为实时控制依据。

## 5. 三种设备接入方式

### 5.1 模拟设备

适合演示、培训和规则验证。

进入“设备中心 → 设施与回路／智能电表”，点击新增，来源选择“模拟设备”。保存后会立即产生带演示标记的数据。模拟设备可以用来体验功率、费用、告警和控制流程，但不能作为真实现场证据。

### 5.2 第三方 API 设备

适合已有电费、余额或电量查询平台的场景。

1. 在“智能电表”点击新增电表。
2. 来源选择“第三方 API 平台”。
3. 按平台实际能力填写请求地址、请求方式、请求头、请求参数和返回字段路径。
4. 只填写接口确实提供的字段；没有功率就不要配置功率。
5. 保存后点击“立即查询”，核对读数、时间与业务状态。
6. 确认无误后再设置自动查询时段和每日额度。

远程平台必须使用 HTTPS，本机模拟接口可以使用 HTTP。凭据由 Windows 当前账户加密保存。详细字段映射和完美校园协议实例见[第三方 API 设备说明](第三方API设备说明.md)。

### 5.3 HTTP 网关设备

适合自行开发适配器，对接电表、智能插座、断路器或控制器。

1. 建立正式管理员账户并登录。
2. 到“后端设置 → 账户与网关”登记网关。
3. 立即保存网关 ID 和只显示一次的令牌。
4. 在目标空间新增“HTTP 网关设备”，选择刚登记的网关。
5. 网关向遥测接口上报功率、电压、功率因数和继电器状态。
6. 需要控制时，网关领取指令、检查现场条件、执行硬件动作并回传实际状态。

遥测接收成功只表示数据已保存；控制指令只有在回执状态与目标一致时才显示“执行已确认”。完整请求格式、序号规则、超时和回执流程见[网关接口说明](网关接口说明.md)。

## 6. 运行大屏怎么读

- 当前功率：当前仍在线且确有功率数据的入账设备合计。
- 今日用电：由有效采样区间积分或第三方累计量差额形成。
- 今日费用：按当前有效电价版本估算，不代替供电结算账单。
- 待处理异常：尚未完成人工处理闭环的事件数量。
- 余额与处理时限：显示有余额能力的电表及保守续航估算。
- 实时功率曲线：默认最近3分钟；滚轮可查看15秒至30分钟范围。

如果顶部显示“采集异常”，先检查服务中心是否运行、设备最后更新时间、网关在线状态或第三方请求记录。不要把离线设备显示的旧读数当成当前状态。

## 7. 监控画面

天枢支持场景示意、JPEG 实时快照、MJPEG 图片流和浏览器可播放的视频地址。RTSP 需要先由网关转换为浏览器可用格式。

使用独立模拟平台时：

1. 运行 `Tianshu.Simulator.exe`。
2. 打开“模拟监控”，确认四张模拟照片轮播。
3. 在天枢“监控画面”点击“新增画面”。
4. 类型选择“JPEG 实时快照”。
5. 默认地址填写：

```text
http://127.0.0.1:8792/mock/camera/snapshot.jpg
```

天枢每秒获取当前 JPEG，新图加载成功后再替换旧画面。模拟平台支持四张照片、默认5秒切换、暂停、间隔设置和本机照片替换。本阶段不进行人员识别、目标检测或画面告警。详见[模拟平台使用说明](模拟平台使用说明.md)。

## 8. 告警规则与处理闭环

进入“告警中心 → 新增规则”，可以配置功率、费用／电量、余额、非营业时段和数据异常等规则。建议每条规则至少填写：

- 阈值与级别；
- 持续时间，过滤瞬时波动；
- 恢复稳定时间与滞回，防止反复跳变；
- 通知间隔，避免重复轰炸；
- 紧急事件的超时升级时间。

事件处理状态依次为“待处理 → 已确认 → 处理中 → 已关闭”。监测是否恢复是单独字段：设备恢复正常不会自动代表人工处理完成。打开事件可指定负责人、填写处理说明、上传现场照片并查看发生时刻曲线。

## 9. 电价、预算与预测

在“后端设置 → 空间与计费”配置固定、分时或阶梯电价，并设置生效时间。新版本只影响生效后的统计，不应修改过去报表。月度预算用于提醒和超支判断，默认不会因为超预算自动断电。

“预测中心”的本地预测至少需要3个完整有效历史日。历史不足时会明确显示学习中。预测值和费用是工程参考，不是供电公司的结算结果。

## 10. AI 分析

AI 分析与本地预测是两个独立功能。管理员进入“后端设置 → AI 分析 → 配置 AI 接口”，填写兼容 Chat Completions 的接口地址、模型名称、API Key、预设提示词和最近7／14／30天数据范围。

使用步骤：

1. 保存并启用 AI 接口。
2. 进入“预测中心”，点击“AI 分析”。
3. 检查接收地址、模型、数据范围、提示词和即将发送的数据包。
4. 点击“确认发送并分析”。
5. 在结果卡片或历史分析中查看真实返回内容。

默认使用匿名设备代号，不发送接口密钥、账户、现场照片和处理说明。开启“发送空间与设备原名”前，应确认服务商可信。远程 AI 接口必须使用 HTTPS，调用可能产生费用。AI 只输出文字建议，不具备设备控制权限；未配置接口时系统不会伪造 AI 结果。

## 11. 通知渠道

在“后端设置 → 通知渠道”可新增通用 Webhook、飞书机器人或 SMTP 邮件渠道，并限定空间、级别和接收时段。飞书机器人使用群聊自定义机器人的 Webhook 地址；若机器人开启了签名校验，还要填写签名密钥。保存后先使用“发送测试”，再检查发送记录。飞书渠道会检查 HTTP 状态和业务返回码，失败记录会显示原因并支持手动重试。

SMTP 密码和其他凭据不会在页面回显。生产环境应使用专用通知账户，并确认服务器、端口、SSL、发件人和收件人配置一致。

## 12. 账户与权限

- 查看者：查看被授权空间的数据，不能控制设备或修改配置。
- 操作员：可处理事件和执行允许的设备控制。
- 管理员：管理空间、设备、账户、网关、通知、AI 和维护操作。
- 演示管理员：用于本机首次体验，不能登记或控制真实网关设备。

管理员可为成员选择允许访问的空间。停用成员后，其现有访问不应继续作为有效操作入口。

## 13. 备份、恢复与端口

进入“后端设置 → 运行与维护”：

- 上传 Logo：支持 PNG、JPEG 和 WebP。
- 修改端口：`0` 表示自动分配，保存后重启程序生效。
- 下载备份：在升级、恢复或重要配置调整前执行。
- 恢复备份：会覆盖当前账户、设备和历史记录。
- 恢复出厂设置：永久清空列出的记录，需要明确文本和管理员密码确认。

备份包含敏感配置。凭据受当前 Windows 账户保护，换电脑或换 Windows 账户恢复后可能需要重新填写。恢复和出厂操作不可撤销，操作前务必保留备份副本。

## 14. 推荐的日常工作流程

1. 运行大屏查看异常、余额、费用与处理时限。
2. 出现告警后进入事件详情，确认数据时间和来源。
3. 分配负责人并记录现场处理过程。
4. 如需远程控制，核对目标设备、受影响负载、保护状态和操作原因。
5. 等待真实执行回执，不能把“已下发”当成“已断电”。
6. 确认设备监测恢复后，再关闭人工处理事件。
7. 每周查看预测、夜间负荷和设备贡献；每月核对电价版本、预算和数据完整度。
8. 重要配置变更前下载备份。

## 15. 常见问题

### 页面打不开

确认“天枢能源 · 本地服务中心”仍在运行。关闭窗口通常只是收至托盘；选择“退出服务”才会停止后台。端口修改后应以服务中心显示的新地址为准。

### 功率显示“暂无数据”

检查设备是否确实提供功率字段、最近10秒是否有有效采样、是否在线并计入当前空间。只有余额的第三方接口不能显示实时功率。

### 下发断电后为什么不是“成功”

系统会区分待领取、网关已领取、执行已确认、执行被拒绝、超时和结果未知。只有设备回读状态与目标一致，才算执行确认。

### 第三方余额不变，为什么没有实时功率

余额是低频计费读数，不是功率。系统可以利用前后余额差估算一段时间的用电量，但不能还原不存在的秒级负荷曲线。

### AI 按钮不可用

管理员需先在“后端设置 → AI 分析”配置并启用接口。操作员可以执行已配置的分析，但不能查看或修改密钥。

### 能否直接在其他电脑或手机访问

当前版本只监听 `127.0.0.1`，定位为 Windows 本机应用。不要通过关闭安全机制或随意端口转发来暴露服务；局域网与公网部署需要单独设计身份认证、TLS、防火墙和访问控制。

## 16. 当前能力边界

当前版本尚不宣称完成供电账单核对、完整费用分摊、个性化长期基线、所有真实设备自动化冲突策略或任意品牌硬件协议。真实 Webhook／SMTP、校园接口和硬件控制需要使用者自己的合规凭据及现场联调。

任何远程断电都可能影响整条回路。正式使用前，应完成设备映射、保护回路确认、现场应急方案、权限管理和实际回执验证。
